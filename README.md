# Abissal

A daily trivia game in Portuguese where the obvious answer loses. Seven prompts a day, 25 seconds each: any correct answer counts, but the fewer players who think of it, the deeper your lure sinks.

**Stack:** static site on GitHub Pages · Supabase (Postgres + Row Level Security + anonymous auth + an Edge Function) · Gemini API (free tier) to judge answers that are not on the built-in lists.

```
site/ (GitHub Pages)  ──►  Supabase Postgres      answer counts, daily scores, leaderboard
                      ──►  Edge Function "judge"  ──►  Gemini API   (only for unlisted answers)
```

| Path | What it is |
|---|---|
| `site/index.html` | The game |
| `site/admin.html` | Your review page for answers the judge accepted or rejected |
| `site/prompts.json` | 143 prompts and their known answers, generated by `gen/` |
| `site/config.js` | Your Supabase URL and public key (step 4) |
| `supabase/migrations/…_init.sql` | Tables, security rules and the functions the site calls |
| `supabase/functions/judge/index.ts` | The judge: checks an answer with Gemini, caches the decision, enforces a daily limit |
| `gen/` | Python lists and generator for `prompts.json` |
| `.github/workflows/pages.yml` | Publishes `site/` to GitHub Pages on every push to `main` |
